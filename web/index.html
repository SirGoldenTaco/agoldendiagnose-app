PC and internet

    
Watch my PCProcessor, memory, graphics card, drives, and what Windows writes in its event log. Problems are written down on the PC tab.

    
Watch my internetEvery 10 seconds: does the router answer, does the internet answer, do names resolve. Uses a few bytes each time.

    
Tell me when something goes wrongA Windows notification for problems and warnings.

    
Memory counts as almost full atFor a minute or more.

    
The graphics card counts as too hot atFor 30 seconds or more (NVIDIA cards; others don't report it).

    
Keeping it running

    
Keep aliveIf the app is ended from Task Manager or crashes, it starts itself again within seconds, hidden next to the clock. It also opens when you sign in to Windows. Only its own Quit stops it.

    
Ask before quittingQuit from the icon next to the clock asks first, so it isn't closed by accident.

Linux

    
Steam launch optionLinux hides how a game ended from outside programs. Put this in a game's launch options in Steam (Properties › General › Launch options) and the report gets the game's real exit code and everything it printed. It works while aGoldenDiagnose is closed too: the report is made the next time it opens.

    
Proton's own log, for games started that wayProton writes a detailed log of each run, which is added to the report. It can slow a game down and grow large, so it is off until you turn it on.

    
Show in the applications menuAdds aGoldenDiagnose to your desktop's applications menu (one small file in ~/.local/share/applications). Off removes it.

    

  

  

    
AI

    
With your Claude API key, a report gets an "Explain with Claude" button: Claude reads the summary and the important log lines and explains the crash and what to try, in plain words.

    

    
The key stays on this PC and is sent only to api.anthropic.com, together with the report's text when you press the button.
